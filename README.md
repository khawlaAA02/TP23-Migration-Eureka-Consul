# TP Kubernetes – Déploiement d’une application Spring Boot avec ConfigMap

## Objectif du TP

Ce TP a pour objectif de déployer une application Spring Boot dans un cluster Kubernetes (Minikube), de l’exposer via un Service NodePort, puis d’externaliser la configuration de l’application à l’aide d’une ConfigMap.

L’application expose une API REST permettant de tester le bon fonctionnement du déploiement.

## Technologies utilisées

- Java 17

-Spring Boot
- Maven
- Docker
- Kubernetes
- Minikube
- kubectl
